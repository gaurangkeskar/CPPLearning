### Constness
#### Problem Definition

Create a class myConst that manages a list of integers. Implement functions to add integers to the list, retrieve the sum of the list, and retrieve the list itself.
Use const appropriately in member functions and demonstrate its effect.

#### A const pointer is a pointer that cannot be changed to point to a different memory location after it is initialized. ||  int* const ptr;

#### A pointer to const data points to data that cannot be modified through that pointer. || const int* ptr;

#### A const pointer to const data is a pointer that cannot be changed to point to a different location, and the data it points to cannot be modified through that pointer. ||  const int* const ptr;
